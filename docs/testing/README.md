# VolunteerConnect Testing

This folder contains the testing rules the whole team follows.

- `TESTING_STANDARD.md` explains the five test types, file format, and completion rules.
- `TEST_MATRIX.md` maps each product feature to its prepared test skeletons.
- `TEAM_BRIEFING.md` is the short version to share with contributors.
- `MANUAL_E2E_CHECKLIST.md` is used once the automated test backfill is ready and the release candidate is stable.

Detailed cases live directly in the prepared test files as `it.todo(...)`. Team allocation and progress are intentionally not recorded here; the SA may assign files in any way that suits the team.
